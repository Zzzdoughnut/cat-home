# 🐾 口苗口苗博客 (Meow Meow Blog)

这是一个基于 **Vue 3 + TypeScript + Vite** 构建的高端、充满治愈感的猫猫主题博客。它采用了现代化的设计语言（如玻璃拟态、动态流光背景）和丰富的交互效果，专门用于记录和展示小猫 蒜蓉 的日常生活。

## ✨ 项目亮点

- **沉浸式视觉体验**：使用了深色的暖调设计，配合动态的渐变流光（Blob）背景和微粒纹理。
- **现代化技术栈**：Vue 3 Composition API + TypeScript + Vite。
- **原子化 CSS (UnoCSS)**：极致的样式控制，支持高度定制的渐变色 and 自适应布局。
- **趣味交互组件**：
  - **喵喵计 (Meow-o-Meter)**：可视化 蒜蓉 的喵叫能量分贝。
  - **零食挑战 (Treat Challenge)**：互动式投票系统，模拟为猫咪赢得零食。
  - **猫咪档案卡片**：展示 蒜蓉 的品种、技能树、心情状态及秘密基地。
  - **纸箱收藏夹**：蒜蓉 亲选的高分纸箱清单。
- **响应式设计**：完美适配手机、平板及 PC。

## 🛠 技术实现

- **核心框架**: Vue 3 (Script Setup)
- **样式方案**: UnoCSS (Atomic CSS) + Vanilla CSS (Glassmorphism)
- **状态管理**: Vue 3 Reactive State
- **动画效果**: CSS Keyframes + UnoCSS 动画预设
- **字体方案**: Outfit & Quicksand (Google Fonts)

## 🚀 快速开始

1. **安装依赖**：

```bash
npm install
```

2. **启动开发服务器**：

```bash
npm run dev
```

3. **构建生产版本**：

```bash
npm run build
```

## 📂 项目结构

- `src/components/Background.vue`: 带有动态流光的全局背景。
- `src/components/Navbar.vue`: 玻璃拟态导航栏。
- `src/components/Hero.vue`: 带有猫咪动态状态和核心统计数据的首屏。
- `src/components/CatProfile.vue`: 包含档案、技能树、互动挑战、心情追踪及纸箱收藏的综合组件。
- `src/components/ProjectGrid.vue`: 每日喵语日记墙。
